# Contributing

Small fixes and improvements are welcome.

## Local checks

1. Start a server from the repository root with `python -m http.server 8000`.
2. Open `http://localhost:8000`.
3. Verify both picker modes with mouse, touch, and keyboard controls.
4. Confirm that reduced-motion mode still produces a result.
5. Check that the site continues to work after refreshing offline.

Keep changes focused, dependency-free, and compatible with GitHub Pages.
